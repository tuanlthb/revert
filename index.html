Cách lấy & tự động đồng bộ Token GHN

1
Cách 1 (Tự động 100% ngầm): Cài đặt / Cập nhật Script Tampermonkey v3.1

Nếu trình duyệt đã có tiện ích Tampermonkey, bấm nút bên dưới để cài đặt/cập nhật lên bản v3.1. Sau đó chỉ cần mở tracuunoibo.ghn.vn là Token tự động đẩy lên Cloud và truyền thẳng sang web này:

Cài đặt / Cập nhật Tampermonkey Script (v3.1)
2
Cách 2 (Không cần cài tiện ích): Kéo nút Bookmarklet 1-Chạm

Kéo nút cam bên dưới thả lên Thanh dấu trang (Bookmarks Bar). Khi đang ở trang tracuunoibo.ghn.vn, bấm vào nút đó trên thanh dấu trang — nó sẽ tự động lấy Token sống, đẩy lên Google Script Cloud và mở ngay trang Revert Hub đã kết nối sẵn:

⚡ Kéo tôi lên Thanh Dấu Trang: "Đồng Bộ Token GHN"
3
Cách 3: Lấy & Đồng bộ bằng 1 dòng lệnh Console (F12)

Tại trang tracuunoibo.ghn.vn, bấm F12 > tab Console, dán lệnh sau và ấn Enter (tự động Copy + đẩy lên Cloud + mở trang Revert):

var t=localStorage.getItem('token')||sessionStorage.getItem('token');copy(t);window.open('https://tuanlthb.github.io/revert/?token='+t);

Tự Động Kết Nối & Đồng Bộ Token

Tự động lấy Token từ tracuunoibo.ghn.vn & đẩy lên Cloud
Cài đặt/cập nhật Script Tampermonkey v3.1 (hoặc kéo nút Bookmarklet lên thanh dấu trang). Khi bạn mở tracuunoibo.ghn.vn, Token sống sẽ tự động đẩy lên Google Script bên dưới cho toàn bộ đội ngũ!
Cài / Cập nhật Tampermonkey v3.1 ⚡ Kéo lên Bookmark Bar: "Đồng Bộ Token GHN"
Trạng thái: Chưa cấu hình
Hướng dẫn tạo Link Google Apps Script miễn phí vĩnh viễn (1 phút):
  1. Truy cập script.google.com và bấm Dự án mới (New Project).
  2. Xóa toàn bộ mã cũ, bấm nút Copy Mã Script bên dưới dán vào và bấm Lưu (Ctrl+S).
  3. Bấm nút Triển khai (Deploy) ở góc trên bên phải > chọn Tùy chọn triển khai mới (New deployment).
  4. Chọn loại: Ứng dụng web (Web app). Tại mục Ai có quyền truy cập (Who has access), chọn Bất kỳ ai (Anyone).
  5. Bấm Triển khai và sao chép đường link https://script.google.com/macros/s/.../exec dán vào ô bên trên!
